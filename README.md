# QVR

QVR is a free Android video recorder. One tap on a home-screen icon starts recording, with the screen off if you like. No internet access, no adverts, no account. In beta.

Website: https://customgpter.github.io/qvr/

Download: https://github.com/CustomGPTer/qvr/releases/download/v2.4.0-beta1/QVR.apk
